KiranaTrack is a free, superlight web app built to solve a real problem: India's 12M+ kirana stores lose ₹30,000–₹80,000 annually due to expired and untracked inventory — and 85% of them still rely on paper.
I built KiranaTrack as a single-file HTML app with zero backend, zero installation, and full offline support. It runs on any device — desktop, tablet, or mobile — instantly.
Key Features:
• Color-coded expiry tracking (Green / Yellow / Red)
• Smart alerts before products expire
• Visual analytics — category breakdowns, monthly trends, loss estimation
• Full history & audit log
• Dark/Light mode
• PWA-ready (add to homescreen)
Compared to paid tools like Vyapar or Zoho Inventory, KiranaTrack is the only free, mobile-optimized, expiry-first solution designed specifically for small kirana store owners.
Tech: HTML5 · CSS3 · Vanilla JavaScript · LocalStorage · PWA · Responsive Design
